# Customer Management System (CMS) - Sprint 1

## 🚀 Getting Started

1. Clone the repo.
2. Run `npm install`.
3. Create a `.env` file based on `.env.example`.
4. Run `npm run dev`.

## 🛠 Branching Strategy

- **main**: Production only. No direct pushes.
- **dev**: The main development branch. All PRs must merge here first.
- **feat/name**: Individual feature branches.

## ⚖️ Rules

- All PRs require at least 1 approval.
- Do NOT commit your `.env` file.
